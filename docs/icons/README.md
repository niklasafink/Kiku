# Icon drafts

Five candidates for the Kiku mark, all 512×512 with the same gradient tile. `e-kiku.svg` is
the one in use (`src/app/icon0.svg`, the PNGs next to it and in `public/icons`, the link preview in
`src/app/opengraph-image.tsx`). Inside the app the name is real text, see `src/components/KikuWordmark.tsx`.

| File | Idea |
|---|---|
| `a-stimme.svg` | A flashcard with a spoken answer on it: three voice bars, the loudest green like a correct segment; a second card behind it |
| `b-k.svg` | A bold K whose lower leg is the green check stroke (the previous icon) |
| `e-kiku.svg` | The word "kiku" in lowercase, no tile, both k's with the green lower leg (in use) |
| `c-sprechblase.svg` | A speech bubble as the card, voice bars inside |
| `d-satz.svg` | A card with text lines, one segment marked green: the graded solution |
