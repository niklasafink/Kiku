# Icon drafts

Four candidates for the Kiku mark, all 512×512 with the same gradient tile. `b-k.svg` is
the one in use (`src/app/icon.svg`, `src/app/apple-icon.tsx`, `src/components/KikuMark.tsx`).

| File | Idea |
|---|---|
| `a-stimme.svg` | A flashcard with a spoken answer on it: three voice bars, the loudest green like a correct segment; a second card behind it |
| `b-k.svg` | A bold K whose lower leg is the green check stroke (in use) |
| `c-sprechblase.svg` | A speech bubble as the card, voice bars inside |
| `d-satz.svg` | A card with text lines, one segment marked green: the graded solution |
